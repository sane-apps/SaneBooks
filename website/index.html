How it works

Three moves. Zero spend risk.

ZecBooks is the accountant layer for shielded Zcash — not a wallet, not CipherPay.

Import a viewing key

Paste a UFVK from Zashi or Zodl, or import from a supported wallet export. UIVK works in degraded receivables mode with a permanent banner.

Build the private ledger

Classify income, change, expense, and fees. Tag memos. Keep amounts discreet when you need the screen friendly for shared desks.

Share a proof pack

Pick the rows, set an expiry, export an encrypted pack. Your reviewer opens it in Reader — no vault, no viewing key, no spend path.
