How to export a UFVK from Zashi

Zashi holds the wallet. ZecBooks holds the books. Move a UFVK across — never the seed.

By SaneApps · August 4, 2026

The short answer: In Zashi, open the viewing-key / account export path for a UFVK, copy it once into ZecBooks Import, and confirm the vault shows view-only mode.

Before you start

  • Zashi installed and unlocked on your Mac or phone workflow you already trust.
  • ZecBooks installed from the official Mac release.
  • A private screen — treat the UFVK like a password you will not reuse in chat.

Export and import

  1. Open Zashi’s viewing-key export

    Use Zashi’s documented account or advanced export for a Unified Full Viewing Key (UFVK). Do not export seed words.

  2. Copy once, paste into ZecBooks

    In ZecBooks, choose Import Viewing Key, paste the UFVK, and continue. Prefer paste over screenshots.

  3. Confirm view-only chrome

    The vault should state it cannot spend. If you imported a UIVK instead, expect a permanent degraded-mode banner.

  4. Clear the clipboard

    After a successful import, clear the clipboard so the UFVK is not sitting behind the next paste.

Zodl and other wallets

Any wallet that can export a UFVK works the same way: export view-only material, import into ZecBooks, never move the seed. If a wallet only offers a seed backup, stop — that is the wrong artifact.

Common mistakes

  • Exporting seed phrases because the UI labeled them “backup.”
  • Leaving the UFVK in Notes, Slack, or email drafts.
  • Screenshotting the key for “easier transfer.”
