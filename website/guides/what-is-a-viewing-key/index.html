What is a viewing key?

A viewing key lets software see shielded notes that belong to you. It does not let anyone spend. ZecBooks is built around that line.

By SaneApps · August 4, 2026

The short answer: A viewing key is read-only authority for shielded Zcash. Import a UFVK into ZecBooks. Never paste a seed phrase or spend key.

Why this matters

Shielded Zcash separates seeing from spending. Accountants, auditors, and operators often need the books — not the keys that move funds. ZecBooks only speaks the viewing-key dialect.

UFVK vs UIVK vs seed

KeyWhat it can doIn ZecBooks
UFVKView incoming and change notes tied to the full viewing capabilityPreferred
UIVKIncoming-view only — incomplete booksDegraded mode with a permanent banner
Seed / spend keyCan spend ZECRejected

Safe mental model

  1. Treat the viewing key like a read-only ledger login

    Useful for classification and proof packs. Useless for sending ZEC.

  2. Keep the seed offline and elsewhere

    Wallet seed phrases belong in the wallet’s recovery flow — never in ZecBooks, email, chat, or a proof pack.

  3. Share packs, not keys

    When someone needs evidence, export a scoped proof pack. Do not forward the UFVK.

Common mistakes

  • Pasting a seed because “it is also a key.”
  • Emailing a UFVK “just for the accountant.”
  • Assuming UIVK gives a complete expense picture.
